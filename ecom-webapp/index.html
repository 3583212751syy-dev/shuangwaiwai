展开：三大禁用规则（负利润 / 需资质 / 重复使用）
  • 负利润：主力场景（半价档 + 常规广告率 + 所选物流）单件净利 ≤ 0 → 停止出表
  • 需资质：产品名命中强制资质关键词（食品接触塑料 SNI 7323:2008 / 化妆品·药品 BPOM / 电子产品·儿童用品 SNI / 食品 Halal / 禁售词）→ 停止出表
  • 重复使用：本浏览器记忆库（localStorage）中同产品同平台已生成过 → 停止出表（可勾选跳过）
展开：完整操作步骤
  1. 点击三个上传框，分别选择产品主图、1688采购页截图、目标平台售卖页截图（图片仅在您浏览器本地处理，不上传服务器）
  2. 确认产品名称（自动取自文件名）；选择售卖平台与物流方式；填写采购价与基准售价（截图里的原价）
  3. 勾选要计算的广告费率（可多选）；可调整降价阶梯
  4. 点击「生成专业数据报表」：系统自动执行 资质核查 → 记忆库去重 → 竞品匹配 → 利润矩阵计算
  5. 如触发禁用规则：页面顶部红框显示停止原因与建议，不生成报表
  6. 如通过：下方展示图片对照、利润矩阵、竞品全景、物流对比、决策建议
  7. 点击「下载 .xlsx」保存数据报表（Excel/WPS 可打开）
  8. 换产品时点击上传框替换图片即可；同一产品同一平台不会重复生成（记忆库拦截）
展开：数据说明
  • 汇率：1 CNY = 2,644 IDR（2026-08-27 实时中间价）；amazon-us 按 1 USD = 7.2 CNY
  • 费用：佣金 + 交易费 + 支付费(1%) + 广告率（按平台/勾选）
  • 物流：海运国际段 ¥3/件（LCL USD15-25/m³）+ 印尼段 Rp8k-15k/单；空运 ¥22/件（¥15-25/kg）；包装 ¥1、集运 ¥0.5、清关仓 ¥2
  • 竞品数据：内置价格库自动匹配（1688 价格带 ¥3.60-16.00 + 平台价格带 IDR30k-2.3M）；如需更精确可后续由 AI 搜索注入
