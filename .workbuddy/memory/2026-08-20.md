## ColorForge Pro v9.6 — 清晰度（clarity）增强
- 用户需求：改色相的同时保留清晰度（之前反馈染色后视觉发软/糊）。
- 根因分析：全图换色是逐像素 HSL 重映射、不重采样，分辨率本身无损；"糊"是染色后色相渐变让色块边界变柔、无高频细节增强导致视觉发软。
- 实现 clarity（清晰度）参数：对亮度通道做局部对比增强（unsharp 思路）。
  - 新增 `boxBlurLum`（分离式 O(n) box blur）+ `computeLumDetail`（detail = 原始亮度 - 低通亮度）。
  - detail 按 src 尺寸缓存（`lumDetailCache`），拖滑块不重算，loadImage 清空。
  - 在 applyHslAdjust 三个分支（cinematic / natural / 普通 PS）的 nl 上叠加 `clarityAmt * detail[idx]`，**只动亮度、不碰色相/饱和度**。
  - 放大系数 1.6，滑块 0~100，默认 0（不改变现有预设效果）。
- UI：保护中性下方新增"清晰度"滑块；params / 滑块绑定 / resetSlider / resetAll / applyPreset 全部同步。
- 单元测试（8x4 纹理图，翠绿染色）：clarity=0 vs 60 色相完全一致（160°），纹理亮度差 21→29 增大，验证"改色同时保留/提升清晰度"。
