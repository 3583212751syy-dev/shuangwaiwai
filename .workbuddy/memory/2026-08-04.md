## 图片改色工具 ColorForge

### 任务
用户要求从 GitHub 获取作图相关模型与技能，构建图片改色工具（改特定颜色 / 改全部颜色）。

### 执行过程
1. **搜索 GitHub**：找到两个核心项目：
   - `watermelonPop/replace-color`：基于 Canvas 的点击取色+容差匹配替换
   - `nkzw-tech/palette-swap`：调色板交换+色相偏移，TypeScript，性能优化（Uint32Array）
2. **克隆分析**：两个仓库均克隆到本地，分析其核心算法
3. **构建工具**：基于两者技术方案，融合构建 `colorforge.html`（单文件，无外部依赖）

### 工具功能
- **模式1 - 特定颜色替换**：点击画布取色 / 手动选色 → 设目标色 → 容差匹配 → 边缘柔化选项
- **模式2 - 全局色调调整**：色相偏移(-180~180°) + 饱和度 + 亮度，实时预览
- **模式3 - 全部改色**：保留明暗(基于HSL亮度重映射) 或 纯色填充，可调强度
- 主色调自动提取（量化采样+排序）
- 拖拽上传 / 重置 / 下载PNG

### 技术要点
- RGB 欧氏距离平方做容差匹配
- HSL 色彩空间做色调调整
- smoothstep 做边缘柔化
- 32级量化做主色提取
- 采样优化大图性能

### 文件位置
- 本地：`colorforge.html`
- 双接口共享：`\\Os-20250608fqtb\双接口\workbuddy\colorforge.html`
- 参考仓库：`replace-color/` 和 `palette-swap/`

## 批量改色 v2 优化（2026-08-05）

### 用户反馈
"有什么变化吗，识别图片给我加大色彩范围，选择只能一点，改变颜色一定要出现我要求的颜色"
- 上传带蓝色钻石图案的图片，默认源色 #FFFFFF 无法匹配 → 没替换
- 手动选色流程繁琐

### 改进 `batch-colorforge.html` v2
- **去掉源色手动选色框**：源色只能通过点击图片 OR 点主色板选择（"一点"）
- **自动主色板**：上传图片后立即提取 Top 12 主色 → 大色块展示 → 一键选中
- **容差扩大到 0-500**：默认 80，覆盖更大色彩范围
- **预览开关**：勾选后匹配区域实时红色高亮，所见即所得
- **像素计数**：选完源色立刻显示"匹配 N 像素"，避免生成后才发现无效
- **找不到匹配时**：自动提示提升容差到 200 重试
- **默认硬替换**：移除柔化默认开启，避免结果色被混合稀释
- **保留透明**：PNG alpha 区域不被破坏
