## 图片改色工具 ColorForge

### 任务
用户要求从 GitHub 获取作图相关模型与技能，构建图片改色工具（改特定颜色 / 改全部颜色）。

### 执行过程
1. **搜索 GitHub**：找到两个核心项目：
   - `watermelonPop/replace-color`：基于 Canvas 的点击取色+容差匹配替换
   - `nkzw-tech/palette-swap`：调色板交换+色相偏移，TypeScript，性能优化（Uint32Array）
2. **克隆分析**：两个仓库均克隆到本地，分析其核心算法
3. **构建工具**：基于两者技术方案，融合构建 `colorforge.html`（单文件，无外部依赖）

### 工具功能
- **模式1 - 特定颜色替换**：点击画布取色 / 手动选色 → 设目标色 → 容差匹配 → 边缘柔化选项
- **模式2 - 全局色调调整**：色相偏移(-180~180°) + 饱和度 + 亮度，实时预览
- **模式3 - 全部改色**：保留明暗(基于HSL亮度重映射) 或 纯色填充，可调强度
- 主色调自动提取（量化采样+排序）
- 拖拽上传 / 重置 / 下载PNG

### 技术要点
- RGB 欧氏距离平方做容差匹配
- HSL 色彩空间做色调调整
- smoothstep 做边缘柔化
- 32级量化做主色提取
- 采样优化大图性能

### 文件位置
- 本地：`colorforge.html`
- 双接口共享：`\\Os-20250608fqtb\双接口\workbuddy\colorforge.html`
- 参考仓库：`replace-color/` 和 `palette-swap/`

### v8.0 重新设计（Git: `4ee2d4e`）

**核心算法 — 真正的 PS 风格 4 大滑块：**
1. **色相 Hue** (-180°~+180°) — 走色环最短路径
2. **饱和度 Sat** (-100~+100) — 0=原图，-100=灰度
3. **亮度 Light** (-100~+100) — 整体明度调整
4. **对比度 Contrast** (-100~+100) — 调整反差

像素级算法：`RGB → HSL → 调整 → RGB`，每个像素独立处理，0 失真。

**16 个预设主题一键应用：**
暖红 / 橙黄 / 金秋 / 翠绿 / 森林 / 青蓝 / 深海 / 宝蓝 / 紫罗兰 / 玫瑰粉 / 复古 / 黑白 / 高对比 / 褪色 / 冷峻 / 原图

**UI 完全重构：**
- **左侧固定 360px 控制面板**（关键！不会被图片遮住）
- **实时大图预览**（拖动滑块立刻看到效果）
- **彩虹渐变背景色相滑块**（一眼识别）
- **灰度→红色渐变饱和度滑块**（专业感）
- **批量生成面板**：已添加主题可视化 chips
- **一键加入全部主题 / 单独下载 / ZIP 打包下载**

**调研参考（GitHub 上找到的专业库）：**
- fabric.js（300KB，全功能画布 + 滤镜）
- pixi-filters（HslAdjustmentFilter 参数最精准：hue -180~180 完全匹配）
- glfx-es6（50KB，最轻量）

最终选择**纯像素级 HSL 算法**，无需任何外部依赖，单 HTML 文件可直接打开。
