# 模特服装精准识别与分割

## 概述

本技能提供时尚图像中模特与服装的精准识别、分割与提取能力。支持多种使用场景：电商服装展示、虚拟试穿、时尚数据集构建、服装区域标注等。

## 核心能力

### 1. 模特区域识别

识别图片中的模特（人物）区域，输出人物掩码或分割结果。

**执行流程：**
1. 接收用户上传的时尚/模特图片
2. 使用人物分割模型（如 SAM、Person Segmentation）识别模特区域
3. 生成模特区域掩码（mask）或分割后的图片
4. 可选：输出模特姿态关键点（pose keypoints）

**触发示例：**
- "识别这张图片中的模特"
- "提取模特区域"
- "帮我分割出人物"

### 2. 服装区域分割

识别并分割模特身上的服装区域（上衣、下装、连衣裙等）。

**执行流程：**
1. 接收包含模特的图片
2. 使用服装分割模型（如 Clothing Segmentation、Fashion Segmentation）识别服装区域
3. 按服装类别生成分割掩码：
   - 上衣（top）
   - 下装（bottom）
   - 连衣裙（dress）
   - 外套（outerwear）
   - 配饰（accessories）
4. 输出分割后的服装区域图片或掩码

**触发示例：**
- "分割这件衣服"
- "识别模特身上的服装"
- "提取服装区域"

### 3. 模特与服装区分

精准区分模特身体区域与服装区域，适用于需要从模特身上"分离"服装的场景。

**执行流程：**
1. 接收模特图片
2. 并行执行：
   - 人物分割（识别模特区域）
   - 服装分割（识别服装区域）
3. 计算交集与差异：
   - 模特区域（人物掩码）
   - 服装区域（服装掩码）
   - 背景区域（剩余部分）
4. 生成对比可视化结果：
   - 原图
   - 模特区域高亮
   - 服装区域高亮
   - 三区域对比图

**触发示例：**
- "区分模特和服装"
- "精准识别模特与服装边界"
- "帮我分开模特和衣服"

### 4. 服装抠图与背景替换

基于分割结果，提取服装区域并替换背景（类似产品白底图效果）。

**执行流程：**
1. 执行服装区域分割
2. 使用分割掩码提取服装区域
3. 去除原背景
4. 替换为纯色背景（默认白色）或用户指定背景
5. 输出抠图后的服装图片

**触发示例：**
- "把这件衣服抠出来"
- "生成服装白底图"
- "服装抠图"

## 技术方案

### 方案 A：使用 Bria API（推荐）

Bria 提供专业的电商图像 API，支持背景移除、服装分割等功能。

**可用工具：**
- `mcp__bria__` 系列工具（如果已配置）
- 或调用 Bria API 直接集成

**优势：**
- 高质量分割结果
- 支持批量处理
- API 稳定可靠

### 方案 B：使用 Remove Background 技能

利用已有的 `remove-background` 或 `image-remove-background` 技能作为基础。

**流程：**
1. 使用背景移除工具分离前景（模特+服装）与背景
2. 进一步处理前景区域，区分模特皮肤与服装
3. 基于颜色、纹理特征或简单的计算机视觉方法划分区域

**限制：**
- 需要额外的逻辑来区分模特与服装
- 精度可能不如专业服装分割模型

### 方案 C：集成专业分割模型

使用开源服装分割模型，如：
- **SegFormer** (Hugging Face) - 通用分割
- **Clothing Co-parsing (CCP)** - 时尚服装解析
- **Fashion Segmentation Dataset models** - 专门针对时尚图像

**实现方式：**
- 调用 Hugging Face Inference API
- 或本地部署模型（需要 Python 环境）

## 执行逻辑详解

### 主流程

```
用户输入 → 触发词匹配 → 选择执行模式 → 处理图片 → 生成结果 → 返回用户
```

### 决策树

1. **用户提供了图片吗？**
   - 否 → 提示用户上传图片
   - 是 → 继续

2. **用户的需求是什么？**
   - 识别模特 → 执行"模特区域识别"
   - 分割服装 → 执行"服装区域分割"
   - 区分两者 → 执行"模特与服装区分"
   - 抠图 → 执行"服装抠图与背景替换"

3. **选择技术方案：**
   - 优先使用 Bria API（如果可用）
   - 其次使用 Remove Background 技能
   - 最后考虑集成专业模型

4. **生成结果：**
   - 可视化结果（标注图、掩码图）
   - 处理后图片（抠图结果）
   - 数据输出（掩码数据、区域坐标）

## 输出格式

### 图片输出
- **标注图**：在原图上叠加彩色掩码，区分不同区域
- **掩码图**：黑白掩码图，白色表示目标区域
- **抠图结果**：透明背景的 PNG 图片

### 数据输出
- **区域坐标**：边界框（bounding box）坐标
- **掩码数据**：二进制掩码数组或 Base64 编码
- **分类结果**：区域类别标签（模特/服装/背景）

## 注意事项

1. **图片质量要求**：输入图片应清晰，模特与服装轮廓明显
2. **复杂场景**：多态特、遮挡、复杂背景可能影响分割精度
3. **服装类型**：紧身衣、透明材质、复杂图案可能增加识别难度
4. **批量处理**：支持批量处理多张图片（需明确说明）
