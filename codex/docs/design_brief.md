## 三、主图设计方案

### 3.1 设计策略

**定位**：对标 Cederberg + Ezusaa 风格 — "有机天然 + 专业功能" 路线，避免 Rooibos Rocks 过于花哨的卡通风格，也避免 Anthony's 过于极简而缺乏信息量。

**配色方案**：

| 用途 | 色号 | 色值 | 说明 |
|------|------|------|------|
| 主强调色 | 琥珀棕 | #C67B4B | 来自竞品 Cederberg/Ezusaa 的暖棕调和优化，呼应茶汤色 |
| 辅助色 | 鼠尾草绿 | #4A7C4A | 来自竞品共性绿色提炼，象征天然有机 |
| 点缀色 | 暖金 | #D4A853 | 来自 Bigelow 的金色调，提升 premium 质感 |
| 背景色 | 暖白 | #FDF9F3 | 柔和米白，比纯白 #FFFFFF 更自然 |
| 深色文字 | 炭灰 | #2C2C2C | 来自 Numi 正文色，柔和于纯黑 |
| 浅色文字 | 米白 | #F5F0E6 | 深色背景上反白文字 |

### 3.2 主图布局方案

```
├──────────────────────────────────────────┤
│                                          │
│        ┌──────────────────┐              │
│        │                  │              │

│  └────────────────────────────────────┘  │

│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘ 1600x1600px 正方形
```

**设计细节**：
- 产品图区域占比约 **65%**（对标竞品 Cederberg 60%、Ezusaa 55%），既突出产品又保留信息展示空间
- 品牌条采用鼠尾草绿 #4A7C4A 作为顶部横幅，与产品牛皮纸包装的棕色调形成绿色-棕色自然呼应
- 金色渐变徽章采用 `#D4A853 → #C67B4B` 行级渐变，GaussianBlur(8px) 阴影，圆角 12px
- 底部属性栏三列均分：`100%天然` | `缓解压力` | `无咖啡因`，用 1px 琥珀棕分割线
- 整体留白约 15-18%，对标 Cederberg 的留白策略

## 五、技术执行规范

### 5.1 图像合成技术参数

| 操作 | 参数 |
|------|------|
| 产品图裁剪 | 智能去除 AI 水印区域，保持 1:1 居中 |
| 图像增强 | 对比度 +15%，锐度 +30%，亮度 +5%，色彩饱和度 +8% |
| 徽章阴影 | GaussianBlur(8px) + offset(3, 3) |
| 卡片阴影 | GaussianBlur(12px) + offset(5, 5) |
| 渐变填充 | 行级渐变 (line_gradient)，非径向 |
| 圆角 | 徽章 12px，卡片 12px，按钮 16px，表格 6px |
| 图片格式 | PNG-24，透明背景保留，最终输出 1600px 宽度 |

### 5.2 配色严格对照

所有设计元素必须使用以下精确色值，不允许偏差：

```
琥珀棕 #C67B4B   — 标题、强调、主按钮
鼠尾草绿 #4A7C4A — 图标底、品牌条、认证标识
暖金 #D4A853     — 徽章、点缀线条、步骤数字
暖白 #FDF9F3     — 主背景
米白 #F5F0E6     — 交替行背景
炭灰 #2C2C2C     — 正文文字
```
