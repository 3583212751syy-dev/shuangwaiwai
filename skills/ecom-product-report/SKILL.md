# 电商产品图片分析报表生成器（ecom-product-report）

## 定位
根据用户上传的产品图片（产品图 / 平台销售页截图 / 1688竞品图 / 表格样式模板），分析图片内容并生成专业选品数据报表（.xlsx，5-sheet）。当前会话模型若无法读图，则接受文字结构化参数作为输入，并在报表中标注"数据来源：用户描述 + 行业估算"。

## 触发条件
用户提供：产品图片（含价格、采购价信息）+ 要求生成"专业版选品分析报表"，且期望按某电商平台的规则计算利润。

## 工作流

### Phase 0：前置筛查（任一不满足 → 停止，不生成报表）
1. **平台资质核查**：用 WebSearch 查目标平台对产品 HS 类目的强制资质要求。
   - 印尼站（Shopee.id / Tokopedia / Lazada.id）：SNI 仅对食品接触塑料（SNI 7323:2008）、电子产品、儿童用品强制；BPOM 仅对食品/化妆品/药品；Halal 仅对食品。衣物收纳/家居收纳等非食品接触类 → 无强制门槛，软合规即可（印尼语标签 + PT PMA 主体 + 原产国标注）。
   - 若命中强制资质 → 立即停止并说明原因。
2. **去重判断**：查本地记忆 / E:\Desktop\*_专业版选品分析报表.xlsx / shuangwaiwai git 仓库，若已存在同产品报表 → 询问用户是否覆盖。
3. **负利润判断**：利润矩阵算完后，若主要场景（最大批量 + 最省物流 + 常规广告率）单件利润 ≤ 0 → 报表顶部标"⚠️ 负利润预警"并列出亏损档位；否则标"✅ 正利润"。

### Phase 1：参数澄清（AskUserQuestion，一次只问一个，按依赖顺序追问）
1. 目标平台（Shopee印尼 / Shopee其他 / TikTok Shop / Lazada 等）
2. 采购价档位（1688最低 ¥3.60-4.50 / 中位 ¥5.50-7 / 中高 ¥10-13 / 用户提供）
3. 店铺类型（跨境店 CB：佣金8%+交易费6% / 本土店 PT：佣金5%+交易费2%）
4. 去重（新项目 / 已做过）
5. 资质状态（用户自处理 / 需要核查）
6. 物流方案（Shopee SLS官仓 / 第三方印尼海外仓+JNE/J&T / 海运空运并列对比）
7. 降价阶梯档数（默认5档：5%/10%/15%/20%/25%）
8. 批量采购梯度档数（默认4档：100/500/1000/3000件）
9. 基准售价（原价 / FLASH SALE价 / 自定义心理价）
10. 广告费率（0% / 5% / 10% / 15% / 多档都算）
11. 广告率布局（完整矩阵 5×4 / 主表+敏感性附表 / 独立子表）
12. 批量采购 sheet 布局（独立 / 合并主表 / 独立+主表联动行）
13. 输出格式（仅 .xlsx / .xlsx+PDF / .xlsx+PDF+MD）

### Phase 2：数据采集
- 汇率：WebSearch 实时 IDR/CNY（或当地货币），如 2026-08-27 为 1 CNY ≈ 2,644 IDR。
- 竞品：1688 价格（用户截图数据点优先，范围如实标注）+ 目标平台同类售价（行业采样）。
- 行业基准：IndexBox 等市场报告（价格带、增长率、竞争强度、物流费率）。

### Phase 3：计算模型
单件利润(CNY) = 售价(IDR)×汇率 × (1 − 佣金率 − 交易费率 − 广告率 − 支付费率) − 采购价 − 国际运费 − 印尼段运费 − 包装费

| 参数 | Shopee印尼本土店 | Shopee印尼跨境店 |
|------|------------------|------------------|
| 佣金 | 5% | 8% |
| 交易费 | 2% | 6% |
| 支付费 | 1% | 1% |
| 物流 | SLS 或第三方海外仓 | 自选物流 |

- 海运 LCL：约 USD 15-25/m³（深圳→Tanjung Priok，20-35天）；折叠后按体积摊 ≈ ¥2-4/件
- 空运：约 ¥15-25/kg（5-10天）；1.1kg 脏衣篮 ≈ ¥20-27/件
- 印尼段 JNE/J&T：Rp8,000-15,000/单 ≈ ¥3-5.7/件
- 批量折扣：100件0% / 500件8% / 1000件15% / 3000件22%（估算，按谈判结果覆盖）

### Phase 4：生成 5-sheet .xlsx（openpyxl）
1. **利润明细**：降价阶梯(5档) × 广告率(4档) = 20 单元格矩阵 + 原价锚点行；底部"批量=3000件"联动行。
2. **竞品全景**：8-11 款 1688 + 平台同类竞品；列：缩略图/名称/价格/月销/评分/对标痛点；含均价、最低、最高、销量集中段摘要。
3. **SWOT 与定价**：四象限 + 定价区间建议 + 注意事项清单（印尼语标签、PT PMA、禁售红线）。
4. **供应链物流**：环节明细表（采购→国内集运→国际段→印尼段）+ 海运 vs 空运双方案对比 + Shopee SLS 备选 + 单件运费推算。
5. **批量采购利润**：起订量(4档) × 广告率(4档) × 物流(2方案) 矩阵；批量折扣0/8/15/22%。

### Phase 5：交付
- 输出路径：`E:\Desktop\{产品名}_Shopee印尼选品分析报表.xlsx`（与桌面现有"专业版"样本同位置同风格）
- 样式：表头深色底白字、冻结首行、列宽自适应、正利润绿色/负利润红色、金额千分位、sheet 命名与模板一致。
- present_files 投递到会话。
- 同步脚本 + 技能到 shuangwaiwai git 仓库（E:\Desktop\双接口\scripts\）。

## 注意
- 印尼强制资质仅限：食品接触塑料(SNI 7323:2008)、食品/化妆品(BPOM)、电子产品/儿童用品(SNI)、药品。
- 软合规必做：印尼语标签、PT PMA 主体、原产国标注、进口商信息。
- 图片无法读取时：接受文字结构化参数，报表标注"数据来源：用户描述 + 行业估算"，并提示切多模态模型后可补图。
