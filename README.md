# MX Studio 商品图片工作室

本地运行，默认使用 ComfyUI，手动切换 OpenAI API。默认输出六张独立的 1200×1200 图片：两张主图、两张详情图、两张场景图。生成结果需核对商品结构和配件数量。

## 安装与访问

1. 解压整个文件夹，双击“安装到D盘.cmd”。所有模型、原图、成品和账号配置默认保存在 `D:\图片AI`。安装会下载大型模型，请保持网络和足够磁盘空间。
2. 安装时设置自己的账号和至少 12 个字符的密码。
3. 双击“启动图片工作室.cmd”，浏览器访问 http://127.0.0.1:3188 。等待设置页的本地服务检查通过。
4. 如需远程访问，双击“开启远程访问.cmd”，使用窗口显示的 HTTPS 地址。地址可能在重启后变化，电脑和服务必须保持运行。登录仍需个人账号密码。
5. 使用“停止全部服务.cmd”停止本项目启动的服务。

## 使用

上传同一产品的 1–3 张照片，填写已确认的产品信息。尺寸图需要提供真实尺寸。主图默认无文字，其他图使用墨西哥西班牙语。每张图片可单独生成、修改提示词、审阅和下载，也可导出 ZIP。API 模式需要自行设置密钥，费用不包含在 ChatGPT 订阅内。

## 验证范围

自动测试覆盖登录、访问限制、保存原图、独立出图、编辑版本和 ZIP 导出，使用模拟出图服务。真实显卡出图速度、模型内存占用、首次安装及远程连通性必须在目标电脑验证，不能以模拟测试代替。

故障日志在 `D:\图片AI\logs`。不要将 ComfyUI 的 8188 端口直接公开。
